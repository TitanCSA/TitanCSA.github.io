Tell two keyboards apart on Windows

Use the Interceptor Keyboard & Mouse input viewer to see which keyboard sent a key. The viewer passes the keys through normally while you observe them.

Download the signed demo installerDownload the input viewer

Install and try it

  1. Connect two keyboards to your Windows 10 (1709 or newer) or Windows 11 x64 PC. If the combined Interceptor edition is installed, follow its removal steps first.
  2. Run InterceptorSetup.exe, accept the administrator prompt and choose Install / reinstall. Restart Windows if requested.
  3. Open InterceptorExampleUI.exe. In Keyboard, select All keyboards and click Observe if observation is stopped.
  4. Tap the same letter on each keyboard in turn. Read last ID below the diagram after each press. Two different IDs show that the viewer can tell the keyboards apart. You can then select a single keyboard in the list. Click Stop when finished.
See where the viewer shows the device ID

If the second keyboard does not appear, check that it works normally in Windows and see the supported device paths. Each demo lasts one hour per Windows boot, starting with the first capture.
