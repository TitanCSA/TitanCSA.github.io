Verify a signed Windows driver package before installation

Use PowerShell to compare the ZIP against the release checksum, inspect the signed catalog and read the package version. This example uses the public Vdevice 1.0.6.0 demo.

Verified with Windows PowerShell 5.1 and Windows SDK SignTool 10.0.26100.0 · 24 November 2026

Open the Vdevice 1.0.6.0 releaseVdevice overview

Compare the ZIP to the publisher's SHA-256

Download Vdevice-Driver-1.0.6.0.zip and SHA256SUMS.txt from the release above. Save them in the same folder and open PowerShell in that folder.

$zip = 'Vdevice-Driver-1.0.6.0.zip'
$namePattern = [regex]::Escape($zip)
$line = Select-String -LiteralPath .\SHA256SUMS.txt `
    -Pattern "^([a-fA-F0-9]{64})\s+\*?$namePattern\s*$"
if (@($line).Count -ne 1) { throw 'Expected one checksum for the exact ZIP name.' }
$expected = $line.Matches[0].Groups[1].Value
$actual = (Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'The ZIP checksum differs from the release.' }
"SHA-256 matches: $actual"

The match identifies the exact downloaded archive. The release page also supplies a separate SDK ZIP, examples and installers, each with its own filename and checksum.

Inspect the catalog and package version

Expand-Archive -LiteralPath $zip -DestinationPath .\Vdevice-Driver-1.0.6.0
Set-Location -LiteralPath .\Vdevice-Driver-1.0.6.0
$signature = Get-AuthenticodeSignature -LiteralPath .\Vdevice.cat
$signature.Status
$signature.SignerCertificate.Subject
Select-String -LiteralPath .\Vdevice.inf -Pattern '^DriverVer\s*=', '^CatalogFile\s*='

The checked archive returned Valid and identified Microsoft Windows Hardware Compatibility Publisher. The INF lists version 1.0.6.0 and catalog Vdevice.cat. Windows uses the catalog named by the INF to verify the package files when staging a Plug and Play package. Microsoft driver catalog documentation.

Check the driver files against the catalog

With the Windows SDK signing tools installed, run these commands in the extracted folder from a Developer PowerShell where signtool.exe is available.

signtool verify /kp /c Vdevice.cat Vdevice.sys
signtool verify /kp /c Vdevice.cat TitanDemoClock.sys

Both commands returned Successfully verified on the pinned archive. These checks use the catalog's signature and file membership. Device availability and application behavior are verified separately after setup on the intended Windows build.

Install and check the active package

Use the installer from the same release and the project installation guide. The Vdevice console installer reports its active image, payload comparison and driver API response with VdeviceSetupConsole.exe /diagnose.
