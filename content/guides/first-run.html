Run the Browser Control SDK test with Python

Install Python 3.10 or later. Open BrowserControl.exe once and follow its WebView2 prompt if it appears. Download browser-sdk-first-run.py into the folder extracted from the Browser Control ZIP. Open PowerShell in that folder.

python .\browser-sdk-first-run.py

The script opens its own browser window, enters Ada on a page served by your PC, clicks Save and prints Saved: Ada. It closes the test window when it finishes.
