Lancer le test Python de Browser Control SDK

Installe Python 3.10 ou une version plus récente. Ouvre BrowserControl.exe une fois et suis la demande d’installation de WebView2 si elle apparaît. Télécharge browser-sdk-first-run.py dans le dossier décompressé du ZIP Browser Control. Ouvre PowerShell dans ce dossier.

python .\browser-sdk-first-run.py

Le script ouvre sa propre fenêtre, saisit Ada sur une page créée par ton PC, clique sur Save et affiche Saved: Ada. Il ferme sa fenêtre à la fin du test.

Pour essayer le client PyPI, lance {{BROWSER_PYPI_INSTALL}} et relance le test avec --installed-client.
