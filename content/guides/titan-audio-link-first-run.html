Route Windows playback to a virtual microphone with Titan Audio Link

Send audio from one app to another through a paired virtual playback and recording device. Use the built-in test signal to verify the pair before connecting your own apps.

Try the matching playback and recording pair

  1. Extract the complete evaluation ZIP. Run Dependencies\TitanAudioLinkSetup.exe with administrator approval. Restart Windows if setup requests it.
  2. Open TitanAudioLink.exe, refresh the endpoint list and select one pair.
  3. Click Test virtual cable. The app sends a known stereo fixture to the selected virtual playback endpoint and checks it at the paired recording endpoint.
  4. When ready, select the pair's playback endpoint in the source app and the matching recording endpoint in the receiving app. Check that both endpoints belong to the same adapter. Remove the virtual devices using the setup's Uninstall option when finished.

The evaluation uses shared-mode WASAPI and native stereo PCM16 at 48 kHz. Select endpoints explicitly inside your apps. Windows microphone permissions can affect access to the virtual recording endpoint.

What the evaluation evidence covers

Evaluation bundle 0.1.1 embeds signed driver 0.1.0.0. The published test evidence covers Windows 10 build 19045 x64 and two virtual audio pairs, including stereo signal transfer, isolation and repeated stream open and close. Windows 11, HVCI and Secure Boot qualification remain outside that evidence for this evaluation bundle. Read the pinned evaluation release and checksum.

The commercial ZIP checked {{COMMERCIAL_CHECK_DATE}} is 0.2.1.2 with signed driver 0.2.1.0. The exact commercial package installed in a Windows 11 build 26100 guest with Secure Boot, and its status command reported one started virtual audio pair. Signal transfer for this commercial build remains a separate test.
