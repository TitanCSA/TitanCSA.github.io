Install and test one virtual cable

  1. Extract the complete Windows x64 demo ZIP. Run Installers\TitanAudioLinkSetup.exe with administrator approval. Restart Windows if setup requests it.
  2. Open TitanAudioLink.exe, refresh the endpoint list and select playback and recording endpoints from the same adapter.
  3. Click Test virtual cable. The app sends a generated stereo signal into that virtual playback endpoint and checks the corresponding virtual recording endpoint.
  4. Select the pair's playback endpoint in the source app and its recording endpoint in the receiving app. Windows microphone permissions can affect access to the virtual recording endpoint. Use the installer's Uninstall option to remove the pair.

The shared one-hour demo allowance starts on the first successful capture in a Windows boot. Listing endpoints leaves the allowance unstarted. The supported path is shared-mode WASAPI and the driver transports 48 kHz stereo PCM16. Read the release notes and archive SHA-256.

Verify the pair from PowerShell

Use the bundled console tool from the extracted folder. With one active Titan Audio Link pair, --test selects its two verified endpoints. For multiple pairs, pass the playback and recording IDs from the same adapter as two quoted arguments after --test.

.\AudioLinkCLI.exe --list
.\AudioLinkCLI.exe --test

The test opens the paired virtual microphone and generates its own signal. It leaves Windows default audio devices unchanged.
