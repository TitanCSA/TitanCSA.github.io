Créer une souris USB virtuelle avec Vdevice sous Windows

Crée une souris avec la démo signée, puis envoie un déplacement relatif et vérifie le résultat sur le bureau Windows.

Essayer le panneau de la souris

Utilise Windows 10 version 2004 ou plus récente, ou Windows 11, sur un PC x64 avec les droits administrateur. La démo signée par Microsoft dure une heure par démarrage du noyau Windows, à partir du premier périphérique virtuel créé.

  1. Lance VdeviceSetup.exe, puis choisis l’installation ou la réparation. Redémarre Windows si l’installateur le demande.
  2. Extrais le ZIP des exemples et ouvre VdeviceMouseUI.exe. Clique sur Create device et attends l’état READY.
  3. Éloigne le pointeur du bord de l’écran. Règle x sur 32 et y sur 0. Laisse les boutons relâchés, puis clique sur Send state. Le pointeur doit se déplacer vers la droite. La distance visible dépend des réglages Windows.
  4. Clique sur Release / neutral puis sur Disconnect pour terminer. L’installateur permet de retirer la démo.

Reprendre le même profil en C++

L’exemple configure le descripteur USB HID avec Device_Config, crée le périphérique avec Create_Device, puis envoie un rapport de sept octets avec Send_Input. Le rapport contient cinq bits de boutons, les déplacements relatifs X/Y signés et deux valeurs de molette.

Vérifier le pilote de démo avec Python

Utilise Python 3.10 ou plus récent en 64 bits sous Windows. Télécharge le paquet Python Vdevice et le script de vérification dans le même dossier. Ouvre PowerShell dans ce dossier.

python -m pip install .\{{VDEVICE_PYTHON_WHEEL_FILE}}
python .\python-vdevice-status.py

Avec la démo {{VDEVICE_PYTHON_TESTED_DEMO}} installée, le script affiche la version du paquet Python, l’ABI de la réponse d’état du pilote et l’état du compteur. Juste après l’installation, "trial_started": false indique que le compteur est encore arrêté. L’erreur Windows 2 indique que le script ne trouve pas l’interface du pilote de démo.

Ce qui a été vérifié

La campagne Windows 11 Hyper-V avec Secure Boot a confirmé que la pile USB de Windows consommait les rapports de la souris dans les essais des cinq profils. Le déplacement du pointeur et le comportement de ton application restent à vérifier avec les étapes ci-dessus. Voir la validation publiée avec la démo.

Sous Windows 11 avec Secure Boot, le panneau officiel de la démo 1.0.6.1 a affiché READY puis State sent pour x=32 et y=0. Windows a reconnu la souris HID, puis l’a retirée après Disconnect. Le déplacement du pointeur reste le contrôle manuel de l’étape 3. Voir les résultats du panneau de la souris

Lors d’un essai distinct sous Windows 11, la première souris virtuelle a lancé le compteur. Il a diminué de 300,11 secondes en cinq minutes. Après un redémarrage de Windows, il était à nouveau arrêté avec une heure disponible. L’essai a mesuré les cinq premières minutes. Voir les mesures et la désinstallation.
