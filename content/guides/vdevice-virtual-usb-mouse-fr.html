Créer une souris USB virtuelle avec Vdevice sous Windows

Crée une souris avec la démo signée, puis envoie un déplacement relatif et vérifie le résultat sur le bureau Windows.

Essayer le panneau de la souris

Utilise Windows 10 ou 11 x64 avec les droits administrateur. La démo signée par Microsoft dure une heure par démarrage du noyau Windows, à partir du premier périphérique virtuel créé.

  1. Lance VdeviceSetup.exe, puis choisis l’installation ou la réparation. Redémarre Windows si l’installateur le demande.
  2. Extrais le ZIP des exemples et ouvre VdeviceMouseUI.exe. Clique sur Create device et attends l’état READY.
  3. Éloigne le pointeur du bord de l’écran. Règle x sur 32 et y sur 0. Laisse les boutons relâchés, puis clique sur Send state. Le pointeur doit se déplacer vers la droite. La distance visible dépend des réglages Windows.
  4. Clique sur Release / neutral puis sur Disconnect pour terminer. L’installateur permet de retirer la démo.

Reprendre le même profil en C++

L’exemple configure le descripteur USB HID avec Device_Config, crée le périphérique avec Create_Device, puis envoie un rapport de sept octets avec Send_Input. Le rapport contient cinq bits de boutons, les déplacements relatifs X/Y signés et deux valeurs de molette.

Ce qui a été vérifié

La campagne Windows 11 Hyper-V avec Secure Boot a confirmé que la pile USB de Windows consommait les rapports de la souris dans les essais des cinq profils. Le déplacement du pointeur et le comportement de ton application restent à vérifier avec les étapes ci-dessus. Voir la validation publiée avec la démo.

Dans un essai distinct sous Windows 11 avec Secure Boot, le panneau officiel a affiché READY puis State sent pour x=32 et y=0. Windows a reconnu la souris HID, puis l’a retirée après Disconnect. Le déplacement du pointeur reste le contrôle manuel de l’étape 3. Voir les résultats du panneau de la souris
