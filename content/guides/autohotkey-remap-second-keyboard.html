Remap a second keyboard with AutoHotkey v2

Make A produce B on one keyboard while the same key continues to produce A on your other keyboard.

TitanCSA project documentation · Checked 24 November 2026

Download AutoHotInterceptor 1.0.0Download the AutoHotkey v2 script

Identify the keyboard and run the script

  1. Connect two supported keyboards and extract the entire ZIP. Open AutoHotInterceptor.exe and choose Install / repair driver. Restart Windows if setup requests it.
  2. Choose AutoHotkey v2 and open the input monitor. Press A on each keyboard in turn and note the ID of the keyboard you want to remap. Close the monitor before running the script.
  3. Save the downloaded script in the extracted AHK v2 folder next to Lib. Choose Run a script in the launcher, select it and accept the administrator prompt. Enter the keyboard ID you observed. If devices were reconnected, use the monitor to identify the ID again.
  4. Open Notepad. Press A on the selected keyboard and check for B. Press A on the other keyboard and check for A. Press F8 or exit the script from its tray icon to restore normal input.

The bundle contains the AutoHotkey runtime, native DLLs and the matching Keyboard & Mouse demo installer. The demo allowance is one hour per kernel boot. The monitor can start the allowance. SHA-256 checksums.

Validation

The AutoHotInterceptor project reports a Windows 11 VM test with two keyboard fixtures. An independent Raw Input observer confirmed A-to-B remapping on the selected keyboard and passthrough on the other one. That evidence covers the per-device workflow. Two physical keyboards and the downloadable selector are the manual checks in this guide. Read the validation scope.
