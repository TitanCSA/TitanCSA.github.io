Quel SDK d’entrée Windows choisir ?

Cinq éditions pour remapper des périphériques physiques, créer un périphérique USB virtuel ou reprendre une application qui utilise l’API C d’Interception.

Prévoyez un PC Windows x64 compatible, les droits administrateur pour l’installation et un exemple adapté à votre périphérique. Chaque démo dure une heure par démarrage du noyau Windows. La documentation de l’édition précise quand le compteur démarre et comment désinstaller le pilote.

Passer à la version payante

La boutique affiche 400 € par édition, en un paiement sans abonnement. Le ZIP et la clé d’activation sont délivrés après confirmation du paiement. La Release fonctionne sans compteur de démo. Après un redémarrage de Windows ou un rechargement du pilote, il faut effectuer une nouvelle activation avec accès à Internet.

Le ZIP comprend le pilote de l’édition choisie, les installateurs et les éléments d’intégration. Consultez la fiche d’achat pour le contenu exact et les conditions de licence, notamment si vous comptez intégrer le pilote à un produit distribué.

Vérifier la compatibilité avant l’achat
