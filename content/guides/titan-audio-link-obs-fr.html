Envoyer le son d’une application Windows dans OBS

Avec Titan Audio Link, OBS Studio reçoit le son d’une application Windows sur un micro virtuel.

Télécharger le ZIP signé de la démoRead in English

Ajouter la source dans OBS

  1. Décompresse le ZIP. Lance TitanAudioLinkSetup.exe dans Installers et redémarre Windows si demandé.
  2. Dans ta scène OBS, clique sur + sous Sources, puis sur Capture audio (entrée). Dans Périphérique, choisis le micro Titan Audio Link.
  3. Lance AudioLinkToneExample.exe depuis le ZIP de la démo. Pendant les deux secondes du signal, regarde si la jauge de cette source bouge dans OBS. Choisis ensuite les haut-parleurs Titan Audio Link de la même paire comme sortie dans ton application. Sous Windows 11, ce réglage est aussi accessible pour une application ouverte dans Paramètres → Système → Son → Mélangeur de volume.
Si la jauge reste fixe ou si le son passe deux fois

Vérifie que l’application utilise les haut-parleurs Titan et qu’OBS utilise le micro de la même paire. Si tu as aussi ajouté ce micro dans Paramètres → Audio, désactive ce doublon dans OBS. Après le test, remets la sortie d’origine dans ton application.
