Envoyer le son d’une application vers un micro virtuel sous Windows

Titan Audio Link crée une sortie audio et le micro virtuel associé. Ce que la première application envoie vers la sortie arrive dans le micro de la seconde.

Télécharger la démo signée {{TITAN_AUDIO_LINK_DEMO_VERSION}}Demander la version sans limite de démo

Installer et tester en trois étapes

  1. Installer. Sous Windows 10 ou 11 x64, extrais le ZIP puis lance Installers\TitanAudioLinkSetup.exe. Accepte les droits administrateur et redémarre si l’installateur le demande.
  2. Tester. Ouvre TitanAudioLink.exe, actualise la liste puis choisis la sortie et le micro du même adaptateur. Clique sur Test virtual cable pour vérifier que le signal arrive dans le micro.
  3. Relier tes applications. Dans l’application qui émet le son, choisis la sortie Titan Audio Link. Dans l’application qui doit le recevoir, choisis le micro virtuel associé.

Si le test passe mais que l’autre application reste muette, vérifie sa source micro et ses autorisations dans les paramètres Windows. Pour retirer le câble virtuel, relance l’installateur et choisis Uninstall.

La démo fonctionne pendant une heure par démarrage Windows à partir de la première capture réussie. Le bouton de test démarre cette heure.

Intégrer Titan Audio Link dans une application

L’installateur ajoute la paire de périphériques à Windows. Le SDK C++ permet à ton application de trouver la paire et d’ouvrir les flux WASAPI. Commence par l’exemple qui énumère les périphériques avant d’envoyer ton propre audio.

Premier essai SDK · Documentation C++ · Exemple Rust à télécharger. Pour lancer l’exemple Rust, décompresse le ZIP et exécute cargo run --locked.

Test en ligne de commande et résultat vérifié

Dans le dossier extrait, liste les périphériques puis lance le test quand une seule paire Titan Audio Link est active.

.\AudioLinkCLI.exe --list
.\AudioLinkCLI.exe --test

Le test du ZIP démo 0.2.0 a vérifié 72 000 trames stéréo sur une paire dans une VM Windows 11 x64 avec démarrage sécurisé. Après désinstallation et redémarrage, la paire et le pilote avaient été retirés. Voir le rapport de test.
