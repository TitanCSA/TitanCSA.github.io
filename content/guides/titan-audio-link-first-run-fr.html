Envoyer le son d’une application vers un micro virtuel sous Windows

Titan Audio Link crée une sortie audio et le micro virtuel associé. Ce que la première application envoie vers la sortie arrive dans le micro de la seconde.

Télécharger la démo signée {{TITAN_AUDIO_LINK_DEMO_VERSION}}Discord titancsa · Version sans limite de démo

Installer et tester en trois étapes

  1. Installer. Sous Windows 10 version 2004 ou ultérieure, ou Windows 11 x64, extrais le ZIP puis lance Installers\TitanAudioLinkSetup.exe. Accepte les droits administrateur et redémarre si l’installateur le demande.
  2. Tester. Ouvre TitanAudioLink.exe, actualise la liste puis choisis la sortie et le micro du même adaptateur. Clique sur Test virtual cable pour vérifier que le signal arrive dans le micro.
  3. Relier tes applications. Dans l’application qui émet le son, choisis la sortie Titan Audio Link. Dans l’application qui doit le recevoir, choisis le micro virtuel associé.

Envoyer le son dans OBS Studio.

Si le test passe mais que l’autre application reste muette, vérifie sa source micro et ses autorisations dans les paramètres Windows. Pour retirer le câble virtuel, relance l’installateur et choisis Uninstall.

La démo fonctionne pendant une heure par démarrage Windows à partir de la première capture réussie. Le bouton de test démarre cette heure.

Intégrer Titan Audio Link dans une application

L’installateur ajoute la paire de périphériques à Windows. Le test SDK C++ ci-dessous vérifie qu’une sortie et un micro actifs appartiennent au même adaptateur. Tu pourras ensuite utiliser le SDK pour ouvrir les flux WASAPI.

Vérifie la paire avec C++ ou Python. Pour lancer l’exemple Rust, décompresse le ZIP et exécute cargo run --locked.

Test en ligne de commande et résultat vérifié

Dans le dossier extrait, liste les périphériques puis lance le test quand une seule paire Titan Audio Link est active.

.\AudioLinkCLI.exe --list
.\AudioLinkCLI.exe --test

Le test du ZIP démo 0.2.0 a vérifié 72 000 trames stéréo sur une paire dans une VM Windows 11 x64 avec démarrage sécurisé. Après désinstallation et redémarrage, la paire et le pilote avaient été retirés. Voir le rapport de test.

La révision r2 met à jour le fichier START-HERE.txt avec les guides publics et le contact Discord. Le pilote, les installateurs, le SDK et les exemples correspondent octet par octet au ZIP testé. Voir les empreintes du ZIP et des fichiers.

Vérifier la paire installée avec Python

Utilise Python 3.10 ou plus récent en 64 bits sous Windows. Télécharge le paquet Python et le script de test dans le même dossier, puis ouvre PowerShell dans ce dossier.

python -m pip install .\{{TITAN_AUDIO_LINK_PYTHON_WHEEL_FILE}}
python .\python-titan-audio-link-check.py --expect-installed

Après installation de la démo {{TITAN_AUDIO_LINK_PYTHON_TESTED_DEMO}}, active_pairs: 1 confirme qu’une sortie et un micro actifs sont sur le même adaptateur. Pour lire le nombre avant installation, lance le script seul, sans l’option. L’inventaire laisse le compteur de démo arrêté.
