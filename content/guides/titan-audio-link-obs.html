Send Windows app audio to OBS with Titan Audio Link

Use a virtual microphone in OBS Studio to capture the sound sent by another Windows app.

Download the signed demo ZIPLire en français

Set up the OBS source

  1. Extract the demo ZIP. Run TitanAudioLinkSetup.exe from Installers and restart Windows if requested.
  2. In your OBS scene, click + under Sources and choose Audio Input Capture. In Device, select the Titan Audio Link microphone. On English Windows it appeared as Line In (Titan Audio Link).
  3. Run AudioLinkToneExample.exe from the demo ZIP. While it plays its two-second tone, watch the level meter for that source in OBS. When the meter reacts, choose the matching Titan Audio Link speakers as the output in the app you want to capture. In Windows 11, you can also choose it for a running app under Settings → System → Sound → Volume mixer.
If the meter stays still or the audio doubles

Check that the sending app uses the Titan speakers and the OBS source uses the Titan microphone from the same pair. If you also added that microphone under Settings → Audio, disable the duplicate in OBS. When finished, return the sending app to its original output.

OBS documentation about audio input sources.

The demo allows one hour per Windows boot starting with the first successful capture.

In our Windows 11 VM, the OBS 33.0.3 meter showed silence, received the demo’s 440 Hz tone and returned to silence. See the meter readings and exact versions.
