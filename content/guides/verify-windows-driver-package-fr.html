Vérifier un téléchargement avec PowerShell.

Signature de l’installateur et du pilote

PowerShell a renvoyé NotSigned pour les 11 exécutables d’installation de démo testés. Utilise le vérificateur ci-dessus pour confirmer que ton fichier correspond à celui de GitHub. Windows contrôle le pilote par son catalogue signé pendant l’installation. Voir les versions et empreintes des installateurs testés.

Vérifier une archive et la signature d’un pilote dans PowerShell
Télécharger le ZIP du piloteTélécharger SHA256SUMS.txt

1. Vérifier le fichier téléchargé

Place les deux fichiers dans le même dossier. Ouvre ce dossier dans l’Explorateur, tape powershell dans la barre d’adresse et appuie sur Entrée. Colle ces commandes dans la fenêtre qui s’ouvre.

$zip = 'Vdevice-Driver-1.0.6.1.zip'
$nom = [regex]::Escape($zip)
$ligne = Select-String -LiteralPath .\SHA256SUMS.txt -Pattern "^([a-fA-F0-9]{64})\s+\*?$nom\s*$"
if (@($ligne).Count -ne 1) { throw 'Empreinte introuvable ou ambiguë.' }
$attendue = $ligne.Matches[0].Groups[1].Value
$calculee = (Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash
if ($calculee -ne $attendue) { throw 'Empreinte différente. Télécharge de nouveau le ZIP.' }
"SHA-256 OK : $calculee"

2. Lire la signature et la version

Si PowerShell affiche SHA-256 OK, décompresse le ZIP dans un nouveau dossier. Le fichier .cat contient le catalogue signé du pilote. Le fichier .inf indique sa version.

Expand-Archive -LiteralPath $zip -DestinationPath .\Vdevice-Driver-1.0.6.1
Set-Location -LiteralPath .\Vdevice-Driver-1.0.6.1
$signature = Get-AuthenticodeSignature -LiteralPath .\Vdevice.cat
$signature.Status
$signature.SignerCertificate.Subject
Select-String -LiteralPath .\Vdevice.inf -Pattern '^DriverVer\s*=', '^CatalogFile\s*='

Pour cette démo, tu dois voir Valid, Microsoft Windows Hardware Compatibility Publisher et la version 1.0.6.1. Vérifie que le fichier INF nomme Vdevice.cat. Documentation Microsoft sur les catalogues de pilotes.

Vérifier aussi les deux fichiers du pilote avec SignTool

Si les outils de signature du SDK Windows sont installés, ouvre un PowerShell développeur dans le dossier décompressé. Attends un résultat de réussite pour chaque commande.

signtool verify /kp /c Vdevice.cat Vdevice.sys
signtool verify /kp /c Vdevice.cat TitanDemoClock.sys

Pour tester le pilote après la vérification, installe la démo et crée une souris virtuelle.
