Find published packages for Node.js, PowerShell and native C++. Then install the matching Windows driver from the product's release.

Use Node.js 20 or later on Windows x64 for the three npm bindings. The Vdevice module requires PowerShell 7.4 or later. The SDK package version and the Windows driver version are separate. A registry installation provides the SDK files. Use the matching demo or commercial ZIP for driver installation and activation.

Start with a known result

  • Try the Vdevice mouse example to confirm the Windows device path.
  • Compile the Interception V2 device inventory with the x86 or x64 libraries from the signed demo.
  • Compare the driver demos and commercial packages before switching editions.

The checks for this page covered registry availability and archive contents. The three npm downloads also matched the registry integrity values. Live device support depends on the installed driver, operating system and device profile. See the publisher's SDK package sources and licences.
