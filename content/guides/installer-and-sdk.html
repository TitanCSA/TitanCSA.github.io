Installer, driver and SDK

Start with the installer when you want to try a demo. Use the SDK when you want to write your own app.

Lire en français

Installer
The setup app. Run it once to put the driver in Windows. Restart if it asks.
Driver
The part that runs inside Windows. It lets the example app work with a real or virtual device.
SDK
The code your app uses to talk to the driver. Download it when you want to build or integrate something.

Try a driver in Windows

  1. Pick your edition. Use its matching Setup download below.
  2. Run setup as administrator. For a ZIP, extract it first. Choose Install in graphical setup, or follow the Interception V2 command.
  3. Restart if setup asks. Open the example linked from the project page and follow its first test.

Switching between Interceptor editions that cover the same devices? Uninstall the old edition and restart before running the new setup.

Build the first SDK check

Install Visual Studio 2022 with Desktop development with C++, CMake 3.20+ and Python 3.10+. Extract the first SDK checks ZIP, open PowerShell in that folder and run one command.

python scripts/test_first_sdk.py vdevice --run

The script checks the exact archive’s SHA-256, compiles the sample and runs it. Replace vdevice with the edition ID in the integration manifest. Use --arch x86 for the Interception V2 32-bit library.

  • For Interceptor or Vdevice, Driver answered confirms the status query. Windows 2 means this check could not find the driver interface.
  • For Interception V2, the result is 10 keyboard slots and 10 mouse slots without a driver. These are library positions. To list connected devices later, use the separate inventory example, which opens a context and starts its demo allowance.
  • For Titan Audio Link, 0 Titan endpoints is normal before installation. The check counts Titan audio inputs and outputs without playing or recording sound.

The supplied first checks do not capture input, create virtual devices or start a demo timer. The driver’s package version and the API version printed by a sample are separate values.

For an existing C++ app, use the header and implementation from the same SDK archive. Interception V2 uses an import library and a DLL instead of an implementation file. Put the DLL for your app’s architecture beside its executable. The manifest gives each exact filename.

The manifest includes the SHA-256 of every installer, example and SDK download. See how to check a downloaded file.
