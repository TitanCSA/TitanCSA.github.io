Remapper un deuxième clavier avec AutoHotkey v2 sous Windows

Fais produire B à la touche A sur un clavier précis. La même touche continue de produire A sur ton autre clavier.

Identifier et remapper le bon clavier

  1. Connecte deux claviers pris en charge et extrais le ZIP complet. Lance AutoHotInterceptor.exe et choisis Install / repair driver. Redémarre Windows si demandé.
  2. Choisis AutoHotkey v2 et ouvre le moniteur d’entrée. Appuie sur A sur chaque clavier et relève l’identifiant du clavier à remapper. Ferme le moniteur avant de lancer le script.
  3. Enregistre le script dans AHK v2, à côté du dossier Lib. Choisis Run a script dans le lanceur, sélectionne le fichier et accepte la demande administrateur. Saisis l’identifiant relevé. Si un clavier a été reconnecté, relève à nouveau son identifiant.
  4. Ouvre le Bloc-notes. Appuie sur A sur le clavier sélectionné pour obtenir B. Sur le deuxième clavier, vérifie que A donne toujours A. Utilise F8 ou quitte le script depuis son icône pour rétablir les entrées habituelles.

Le ZIP contient AutoHotkey, les DLL et l’installateur de la démo Keyboard & Mouse. La démo dure une heure par démarrage du noyau Windows. L’ouverture du moniteur peut lancer le compteur. Empreintes SHA-256.

Ce qui a été vérifié

Dans le test AutoHotInterceptor sous Windows 11, un observateur Raw Input a confirmé le changement A vers B sur un clavier de test et le passage normal des entrées sur l’autre. La validation de deux claviers physiques et du script de sélection reste le test à réaliser avec ton matériel. Lire le périmètre du test publié.
