Try the mouse panel

Use Windows 10 version 2004 or later, or Windows 11, on an x64 PC with administrator rights. The download contains the Microsoft-signed demo {{VDEVICE_DEMO_VERSION}}. Its one-hour allowance starts on the first successful virtual device creation per Windows kernel boot.

  1. Run VdeviceSetup.exe and choose Install or Reinstall / repair. Restart Windows if setup requests it.
  2. Extract the examples ZIP and open VdeviceMouseUI.exe. Click Create device and wait for READY.
  3. Put the cursor away from the screen edges. Set x to 32, y to 0 and leave buttons released. Click Send state. The cursor should move to the right. Windows pointer settings affect the visible distance.
  4. Choose Release / neutral and Disconnect when finished. Use the installer’s Uninstall option to remove the demo.

Use the same profile from C++

The mouse example builds a USB HID descriptor in Device_Config, calls Create_Device and sends reports with Send_Input. Its seven-byte report carries five button bits, signed relative X/Y motion and two wheel values. Read the C++ example at the version used for this guide.

Check the demo driver from Python

Use 64-bit Python 3.10 or later on Windows. Put the Vdevice Python wheel and the status script in the same folder. Open PowerShell in that folder.

python -m pip install .\{{VDEVICE_PYTHON_WHEEL_FILE}}
python .\python-vdevice-status.py

With demo {{VDEVICE_PYTHON_TESTED_DEMO}} installed, the script shows the package version, ABI version of the driver's status response and demo timer status. On a fresh install, it reports "trial_started": false. Windows error 2 means the script could not open the demo driver.

Test results and exact wheel SHA-256

Validation

For the signed 1.0.6.0 demo, the Windows 11 Hyper-V lab with Secure Boot enabled confirmed that the Windows USB stack consumed mouse reports during the five-device campaign. Cursor movement is the manual check in this guide. The lab did not assert desktop cursor position or application-specific behavior. Read the signed release validation.

In the Windows 11 Secure Boot run of demo 1.0.6.1, the published VdeviceMouseUI.exe reached READY and confirmed State sent for x=32 and y=0. Windows independently detected the new HID mouse and removed it after Disconnect. The pointer movement is the manual check in step 3. Read the mouse panel test results

In a separate Windows 11 test, the first virtual mouse started the demo timer. The driver counted down by 300.11 seconds over a five-minute run. After Windows Restart, the timer was idle with one hour available. This test covered five minutes. See the countdown and removal results.
