Premiers appels d’API et archives Node.js 1.0.1

Lire l’état du pilote depuis ton projet

Après la commande npm du tableau, enregistre node-sdk-status.cjs dans le dossier de ton projet. Ouvre PowerShell dans ce dossier et lance la commande ci-dessous pour l’édition Interceptor combinée.

node node-sdk-status.cjs interceptor

Le script affiche l’état du pilote. Windows 2 signifie que l’appel ne trouve pas son interface. Pour une autre édition, prends la commande exacte dans le fichier d’intégration.

Pour un module de la Gallery, utilise l’exemple PowerShell après avoir installé le bon module. Le test Interception V2 classe un emplacement de la bibliothèque et fonctionne avant l’installation du pilote.

Télécharger les paquets Node.js 1.0.1 corrigés

La publication GitHub 1.0.1 contient les trois archives et leurs sommes SHA-256. Après téléchargement, lancez npm install ./NOM-DU-FICHIER.tgz avec le nom du fichier correspondant. Les commandes du tableau installent les versions 1.0.0 du registre npm.

  • interceptor-sdk 1.0.1
  • interceptor-keyboard-mouse-sdk 1.0.1
  • interceptor-gamepad-controller 1.0.1

Les archives 1.0.1 indiquent l’installeur InterceptorSetup.exe de la bonne édition quand Windows renvoie l’erreur 2. Chaque paquet est passé par une installation depuis GitHub et une lecture d’état avec Node.js 24.21.0 sur Windows 11 build 26100 avec Secure Boot et le pilote de démo correspondant.

Vérifier l’installation du SDK

Avec Python, vérifiez l’import et la version avant d’installer un pilote.

from importlib.metadata import version
from interceptor import Interceptor

print(version("interceptor-multilang"))

Avec Python ou .NET, installez la démo combinée Interceptor 1.4.22.0 pour le premier essai. Python info() et .NET GetInfo() interrogent le pilote en lecture seule. Les deux paquets 1.0.2 affichent le nom de l’installeur si le pilote manque.

Les cinq modules Gallery 1.0.0 ont été importés sous PowerShell 7.6.6. Si un module Interceptor affiche l’erreur 2 et mentionne Install.cmd, lancez InterceptorSetup.exe depuis la démo de votre édition ou utilisez l’installeur de votre ZIP commercial. Pour Vdevice, utilisez VdeviceSetup.exe avec la démo. Redémarrez Windows si l’installeur le demande.

L’opération check du module InterceptionV2 classe un numéro de périphérique selon l’API C. L’inventaire des identifiants matériels permet de vérifier les périphériques disponibles avec le pilote.
