Each inspected archive supplies a native Windows user-mode library and language binding. Install the matching Windows x64 driver separately from its demo or commercial package. Check that edition’s support for the profiles and features your application needs.

Java and Kotlin

The four Maven Central bindings use the Java 22 Foreign Function & Memory API and require JDK 22 or later on Windows x64. Use the dependency coordinate for your driver. This is the Vdevice dependency for a Maven project.

<dependency>
    <groupId>io.github.titancsa</groupId>
    <artifactId>vdevice</artifactId>
    <version>1.0.0</version>
</dependency>

PHP

The five Composer packages require PHP 8.2 or later and ext-ffi. Install the selected package in your development project. For Vdevice, use the following command.

composer require titancsa/vdevice:1.0.0

Ruby

The four checked gems require Ruby 3.1 or later. Use the package matching the installed Windows driver. For Vdevice, use the following command.

gem install vdevice -v 1.0.0

What was verified

The four Maven JARs matched their published checksums and contained Windows DLLs. The four RubyGems files matched their published SHA-256 digests. The five Packagist packages resolved to TitanCSA versioned source and contained the matching Composer manifests and Windows DLLs. PHP’s syntax check passed for the ten PHP files in those archives. Live calls from these bindings remain a test for the installed driver and your application.
