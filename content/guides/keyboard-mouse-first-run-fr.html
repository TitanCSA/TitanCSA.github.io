Distinguer deux claviers sous Windows

Le visualiseur d’Interceptor Keyboard & Mouse montre quel clavier a envoyé une touche. Les touches continuent de fonctionner normalement pendant l’observation.

Télécharger l’installateur de la démoTélécharger le visualiseur

Installer et essayer

  1. Branche deux claviers sur un PC Windows 10 (1709 ou plus récent) ou Windows 11 en 64 bits. Si tu as l’édition Interceptor combinée, suis d’abord sa procédure de désinstallation.
  2. Lance InterceptorSetup.exe, accepte les droits administrateur et choisis Install / reinstall. Redémarre Windows si demandé.
  3. Ouvre InterceptorExampleUI.exe. Dans Keyboard, sélectionne All keyboards et clique sur Observe si l’observation est arrêtée.
  4. Appuie sur la même lettre tour à tour sur les deux claviers. Lis last ID sous le dessin après chaque appui. Si les deux numéros sont différents, le visualiseur distingue les claviers. Tu peux ensuite en sélectionner un seul dans la liste. Clique sur Stop pour terminer.
Voir où se trouve l’identifiant du clavier

Si le deuxième clavier n’apparaît pas, vérifie qu’il fonctionne dans Windows et consulte les types de périphériques pris en charge. La démo dure une heure par démarrage de Windows à partir de la première capture.

Résultats des tests

Dans une machine virtuelle Windows 11, deux claviers USB virtuels ont envoyé la même touche. Le SDK de la démo a associé chaque appui et relâchement au bon identifiant de clavier. Suis les étapes ci-dessus pour vérifier tes propres claviers.
