When to use it

Use this edition when an existing application expects the original interception_* API. The release bundles the original SDK and seven sample projects, with x86 and x64 application support on x64 Windows.

First validation

Migrate an original Interception application and build the C hardware-ID sample against the published x86 or x64 SDK.

Use Windows 10 1709+ or Windows 11 x64. Follow the migration instructions for removing the old driver and restarting before installing this edition. Test the bundled sample first, then test the specific legacy application. The one-hour demo starts on the first successful context creation after boot.

Scope and evidence

Compatibility covers supported HID keyboard and mouse paths, including compatible USB and Bluetooth HID devices. The upstream SDK retains its original terms.
