When to use it

Build a repeatable input fixture for a Windows application. Start with a virtual keyboard or vendor HID sample, then verify enumeration and the content delivered to an independent receiver. A controller profile adds its own descriptor and protocol requirements.

First validation

Create and test a virtual USB mouse with the signed demo and its bundled control panel.

Verify a custom virtual HID with hidapitester. Read and return a test report using a separate receiver, then check removal.

The signed demo targets Windows 10/11 x64. Start with the installation guide and a bundled example. The demo allows one hour per Windows kernel boot from the first successful virtual device creation.

Scope and evidence

In a Windows 11 build 26100 guest with Secure Boot, the commercial ZIP installed successfully and reported the SDK and installed driver versions when device creation required activation. See the message and activation steps.

The WDF-001 issue tracks two guest crashes during repeated virtual controller/filter teardown. Review the tested scope before using repeated controller removal in a lab workflow. The examples and compatibility notes describe which device paths were exercised. Read WDF-001.

The Microsoft-signed 1.0.6.0 demo includes the fix. It passed repeated teardown and ten rounds of the five device examples in an isolated Windows 11 guest with Secure Boot enabled. The signed commercial update is still pending. Read the test results and status.
