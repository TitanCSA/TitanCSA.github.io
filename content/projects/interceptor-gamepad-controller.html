First steps

  1. Run the demo installer and choose Install / reinstall. Restart Windows if asked.
  2. Connect your gamepad and open the input viewer.
  3. Move a stick or press a button. The viewer should show its value. Click Stop when you finish.

Technical details and support {{RELEASE_DETAILS}}

When to use it

Use the controller examples to compare a stick’s raw response with the result of a deadzone or response curve. Select the exact profile before assuming that a remap observed on a wired Xbox 360 device will carry over to a DS4 or DualSense.

First validation

Test your gamepad and try the stick deadzone example with the signed demo.

Start with the signed demo on Windows 10 1709+ or Windows 11 x64. Observe the connected device in the viewer and check the transformed result in an independent consumer. The demo allows one hour per Windows kernel boot.
