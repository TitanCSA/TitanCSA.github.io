Interceptor

Read or change input from a real keyboard, mouse or supported gamepad.

{{DEMO_DOWNLOAD_LABEL}}

For 64-bit Windows. Use Windows 10 version 1709 or later, or Windows 11. If another Interceptor edition is installed, follow the removal steps first.

Try it

  1. Run the demo installer and choose Install / reinstall. Restart Windows if asked.
  2. Open the input viewer.
  3. Press a key or move a stick. The viewer should show input from your device. Click Stop when you finish.

Technical details and support {{RELEASE_DETAILS}}

When to use it

A desktop remapper can use a spare keyboard for shortcuts and a supported USB controller for gamepad adjustments while keeping device attribution in one integration.

First validation

Start with the signed demo on Windows 10 1709+ or Windows 11 x64. Use the bundled viewer to confirm that each intended device is associated with the filter, then compare an unmodified event with the event independently observed by the target application. The driver demo allows one hour per Windows kernel boot.

Scope and evidence

Controller coverage depends on the device profile and transport. Consult the HID, XInput/XUSB, XInputHID and GIP compatibility notes for your device. The user-mode MIT licence and driver distribution terms are separate.
